# Agent Specification: Product D (Website & Visualizer)

## Overview & Role Mandate
**Role**: Frontend Engineer & Visual Experience Lead  
**Code Ownership**: `site/`  
**Core Objective**: Build the client-facing replay website and visualization dashboard that loads `timeline.json` and renders the agent's survival journey, telemetry trends, and decision rationales.

---

## Deliverables & Milestones

### 1. Tuesday Skeleton Gate
- Construct static HTML5/CSS3/JavaScript web viewer consuming Tech C's sample `timeline.json`.
- Must run completely client-side (no backend requirement), deployable to GitHub Pages or Netlify.
- Scrubber controls: Play, Pause, Step Forward, Step Back, and Speed adjustment (1x, 2x, 5x).

### 2. The Interactive Replay Viewer
- **Island Map Canvas**: Top-down 2D grid rendering terrain tiles (water, plains, forest, mountains, shelter) and the agent's positional track over time.
- **Physiological HUD**: Real-time gauge bars visualizing the 6 core survival needs (hunger, thirst, warmth, energy, safety, morale) and overall stress level.
- **Event Log**: Timeline stream of hazards encountered (storms, animal threats, discoveries, injuries).

### 3. The "Why Did He Do That?" Quantum Inspector
- The signature differentiator for judges:
  - For any selected turn, open an inspection drawer showing:
    1. The agent's current state vector and active prior angles.
    2. The quantum probability distribution across candidate actions.
    3. The contextual event rotation effect (e.g. "Storm rotated priority from foraging to shelter").
    4. The plain-language `reason` string generated by the mind circuit.
    5. Comparison indicator showing what a classical rational agent would have chosen in the same instant.

### 4. Thursday Science Page & Demo-Pack Integration
- Thursday evening: Ingest finalized runs from `demo-pack/` (`run_01` to `run_05`).
- Embed Tech A's interactive circuit diagrams and Tech B's classical vs. quantum divergence charts.
- Render markdown explainer cards authored by Product E into the science deep-dive section (`site/content/`).
