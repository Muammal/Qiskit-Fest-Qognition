# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful. Many scenarios here are based on real disasters in which real people died, so treat them, and the people affected, with care.

To report a problem, use the repository's private reporting under **Security > Report a vulnerability**, and say it is a conduct report. Maintainers may remove content, or block people, who break these rules.
