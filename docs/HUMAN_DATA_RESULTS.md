The one φ fitted on all seven rows is -0.271 rad, stored as `SUPERPOSED_PHI`.

**What the prompt asked for and what was built differ.** Starting the decision qubit in one fixed superposition in every condition does not remove the bound: `U|safe,s>` and `U|danger,s>` are still orthogonal, so the same Cauchy-Schwarz argument applies to the new conditional rates. `mind/tests/test_extended_models.py` shows this numerically. The variant here ties the angle to belief coherence, so a settled belief starts at `|carry>` and reproduces q_S and q_D, and only an unsettled belief starts in superposition. That adds one fitted parameter, and the model is more flexible as a result, which is not by itself evidence for it.
